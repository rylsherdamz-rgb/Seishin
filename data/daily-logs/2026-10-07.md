## Production hardening (follow-up)
- `src/utils/logger.ts`: leveled, scoped logger (warn+ in release); replaced all `console.*`.
- `src/stores/persist.ts`: safe JSON read/write — corrupt data or failed writes no longer crash;
  malformed records are dropped with a log line. Calendar + task stores validate records
  (`isCalendarEvent`, `isTodo`), persist-before-publish, return success booleans, and gained
  `clearAll()` / `getStorageSize()` per RULES. Storage keys unchanged (no migration needed).
- AI agent tools now report failure instead of "success" when the event is rejected.
- `src/constants/copy.ts`: one source for calendar wording; terminology standardised to
  Event / Task / Note ("Todo" removed from user-facing text app-wide).
- Input limits (title 120, notes 5000, 10 attachments), double-tap save guard,
  "Ends the next day" hint, empty-OCR feedback, accessibility roles/labels/states.
- Calendar screen split to 199 lines (`actions.ts`, `CalendarItemSheet.tsx`).
