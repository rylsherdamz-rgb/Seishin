# 2026-10-08

## UI refresh + performance pass
Performance
- Theme palettes cached per (theme, accent): every useColors() call shares one object.
- Note editor autosave debounced (400 ms) — each save re-sorted + serialized the whole notebook.
- Viewing a note no longer bumps updatedAt (exit flush only when edits are pending).
- Notes sort compares ISO strings instead of parsing Dates per comparison.
- Agent chat: memoized MessageBubble + Markdown — streaming re-renders one bubble, not all.
- Notes/Inbox rows extracted into memoized NoteCard / InboxRow; entrance animations only
  on the first screenful (no replay while scrolling virtualized lists).
- Notes tab no longer re-parses the notebook from MMKV on every focus.
- Tabs use freezeOnBlur; calendar handlers stabilized so memoized day cells skip renders;
  calendar dots recompute per visible month/week, not per tap.
- expo-image `Photo` (memory+disk cache, downsampled) replaces RN Image for photos.
- Splash gate 600 ms → 350 ms.

Fixes
- Notes search didn't refilter while typing (missing memo dependency).
- Agent model-tier badge used dynamic class names NativeWind never generated.

UI (from the redesign canvas)
- Tab bar: bolder labels, higher-contrast inactive color, Notes unread badge.
- 30 px headers, 44 px icon buttons, shared Fab, softer cards/chips/segmented control.
- Notes cards (pinned = accent), Inbox rows with unread dot, Agent bubbles + composer.
