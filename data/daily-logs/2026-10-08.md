# 2026-10-08

## UI refresh + performance pass
Performance
- Theme palettes cached per (theme, accent): every useColors() call shares one object.
- Note editor autosave debounced (400 ms) — each save re-sorted + serialized the whole notebook.
- Viewing a note no longer bumps updatedAt (exit flush only when edits are pending).
- Notes sort compares ISO strings instead of parsing Dates per comparison.
- Agent chat: memoized MessageBubble + Markdown — streaming re-renders one bubble, not all.
- Notes/Inbox rows extracted into memoized NoteCard / InboxRow; entrance animations only
  on the first screenful (no replay while scrolling virtualized lists).
- Notes tab no longer re-parses the notebook from MMKV on every focus.
- Tabs use freezeOnBlur; calendar handlers stabilized so memoized day cells skip renders;
  calendar dots recompute per visible month/week, not per tap.
- expo-image `Photo` (memory+disk cache, downsampled) replaces RN Image for photos.
- Splash gate 600 ms → 350 ms.

Fixes
- Notes search didn't refilter while typing (missing memo dependency).
- Agent model-tier badge used dynamic class names NativeWind never generated.

UI (from the redesign canvas)
- Tab bar: bolder labels, higher-contrast inactive color, Notes unread badge.
- 30 px headers, 44 px icon buttons, shared Fab, softer cards/chips/segmented control.
- Notes cards (pinned = accent), Inbox rows with unread dot, Agent bubbles + composer.

## Reflection
- Worked: shared components carried most of the visual change.
- Didn't: still no on-device profiling; numbers above are by construction, not measured.
- Change: add a perf smoke test (render counts) once the reanimated jest mock is fixed.

## Notes: keyboard fix + Material 3 redesign
- Keyboard: editor now lays out above the keyboard (`useKeyboardInset`: window height −
  keyboard top, correct on edge-to-edge Android) with a spacer, instead of padding a
  ScrollView and floating a toolbox over the text. Tapped line scrolls above the keyboard;
  typing at the end follows the caret.
- Editor: M3 top app bar (back, pin), edge-to-edge photo tiles, "Note" body, label chips,
  bottom app bar (add, color, "Edited …", more) riding on the keyboard; add/more sheets;
  note colors; make a copy.
- List: M3 search bar with grid/list toggle, filter chips (Notes / Inbox / labels),
  FlashList masonry grid with full-width Pinned/Others headers, outlined vs tonal cards,
  long-press sheet (pin, color, copy, delete with confirm).
- Tests: shared jest.setup (icons, expo-image, Reanimated, safe-area mocks) — the two
  Notes suites run again; 83/83 passing.

## Reflection
- Worked: making the bar part of the layout removed a whole class of overlap bugs.
- Didn't: keyboard behaviour still needs a real-device check (Gboard + gesture nav).
- Change: prefer layout-based keyboard handling over absolute positioning everywhere.
